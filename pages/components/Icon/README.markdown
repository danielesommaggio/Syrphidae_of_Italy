# Icon

Small inline SVG icons (`IconBug`, `IconImage`, `IconMicroscope`, `IconOk`,
`IconReference`, `IconX`, `iconCitation`, `IconAudio`). They take the text colour
(`currentColor`) and the size of their CSS class.

At the moment they are used only by `../Section/SectionData.vue`, which is itself no
longer on the site (see `../Section/README.markdown`); `IconAudio` is not used at all.
